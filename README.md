## 🚀 Por onde começar

1. [Instalação e criação do primeiro projeto](https://nextjs.org/docs/app/getting-started/installation) — `create-next-app` e a estrutura mínima de uma aplicação.
2. [Estrutura de pastas do projeto](https://nextjs.org/docs/app/getting-started/project-structure) — Onde ficam rotas, componentes e arquivos especiais como `layout.tsx` e `page.tsx`.
3. [Layouts e páginas](https://nextjs.org/docs/app/getting-started/layouts-and-pages) — Como o roteamento por pastas do App Router funciona na prática.
4. [Server e Client Components](https://nextjs.org/docs/app/getting-started/server-and-client-components) — A decisão mais importante do App Router: o que roda no servidor e o que roda no navegador.
5. [Buscando dados (Data Fetching)](https://nextjs.org/docs/app/getting-started/fetching-data) — Como buscar dados direto nos componentes de servidor, sem API intermediária.
6. [Tutorial prático: App Router Dashboard](https://nextjs.org/learn/dashboard-app) — Construa um dashboard completo do zero seguindo o tutorial oficial passo a passo.
7. [Deploy da aplicação](https://nextjs.org/docs/app/getting-started/deploying) — Como colocar o projeto no ar, incluindo a opção de deploy gratuito na Vercel.

## 🤖 IA na prática

Next.js e IA se encontram em dois lugares: usar assistentes de IA para escrever a aplicação mais rápido, e usar o próprio Next.js para construir produtos de IA (chat, agentes, geração de texto/imagem em streaming).

**Para aprender**
- Peça para um assistente de IA **explicar a diferença entre Server e Client Component** em um trecho de código seu, e por que ele colocaria `"use client"` (ou não) naquele arquivo.
- Cole um erro de hidratação (`Hydration failed...`) e peça a causa mais provável — geralmente é HTML inválido ou uso de `Date`/`Math.random()` renderizado diferente no servidor e no cliente.
- Peça para **converter um componente de Pages Router para App Router**, explicando cada mudança (data fetching, `getServerSideProps` → Server Component, etc.).
- Peça exercícios práticos sobre um conceito específico (Server Actions, streaming com `loading.tsx`, cache) e depois valide rodando o código.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para gerar Server Actions, tipar respostas de API Routes e escrever testes com Vitest/Playwright.
- Use o [v0](https://v0.dev/) para gerar interfaces em React/Next.js com Tailwind e shadcn/ui a partir de um prompt ou de um design, e depois trazer o código gerado para o seu projeto.
- Depois de aceitar uma sugestão, rode o build (`next build`) e o lint. Um componente que só funciona com `"use client"` espalhado por todo lugar é sinal de sugestão mal pensada sobre onde os dados deveriam ser buscados.
- Revise sempre o uso de `useEffect` sugerido por IA em Client Components — na maioria dos casos em Next.js, o dado deveria ter sido buscado num Server Component.

**Limites e boas práticas**
- IA tende a **misturar padrões do Pages Router com o App Router** (ex.: sugerir `getServerSideProps` num projeto que já usa App Router). Confira sempre contra a documentação oficial da versão que você usa.
- Ela também erra a fronteira **servidor/cliente**: nem tudo precisa de `"use client"`, e isso aumenta o JavaScript enviado ao navegador sem necessidade.
- Não cole variáveis de ambiente, chaves de API ou dados de clientes em ferramentas de IA sem a política da sua empresa.
- Entenda o que você aceita: em entrevista técnica e em produção, o código é seu.

**Construindo produtos de IA com Next.js**
- [AI SDK (Vercel)](https://ai-sdk.dev/docs/introduction) — SDK oficial em TypeScript para construir chat, agentes e streaming de IA em aplicações Next.js.
- [vercel/ai (repositório)](https://github.com/vercel/ai) — Código-fonte aberto do AI SDK, com exemplos prontos de integração com Next.js.
- [v0 by Vercel](https://v0.dev/chat) — Gera interfaces completas em Next.js/React a partir de prompts em texto ou imagens.
- [Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript) — SDK oficial para usar os modelos Claude a partir de rotas ou Server Actions do Next.js.
- [OpenAI Node/TypeScript SDK](https://github.com/openai/openai-node) — SDK oficial da OpenAI, totalmente tipado, comum em Route Handlers do Next.js.
- [Model Context Protocol — SDK TypeScript](https://github.com/modelcontextprotocol/typescript-sdk) — Crie servidores MCP em TypeScript/Next.js para conectar ferramentas a assistentes de IA.
